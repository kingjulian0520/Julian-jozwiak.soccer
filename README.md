# julian-jozwiak.soccer

Julian Jozwiak's personal soccer portfolio site.

- **Pages:** Home, Academics, Team History, Videos, Achievements
- **Stack:** plain static HTML/CSS/JS, no build step
- **Status:** structure and design in place; real content (bio, stats, videos, etc.) to be added next

## Local development

```
python3 -m http.server 8000
```

then open `http://localhost:8000`.

## Deploying with GitHub Pages

In this repo's Settings → Pages, set "Deploy from branch" to `main` / root.
The site will then be live at `https://kingjulian0520.github.io/julian-jozwiak.soccer/`.
